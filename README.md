# DOMEMO Battle MVP

ユーザー1人 vs CPU1人で遊べる、Streamlit版DOMEMO MVPです。

## 1. このMVPでできること

- 2人対戦：あなた vs CPU
- 1〜7の数字タイルを使用
- 「1」は1枚、「2」は2枚、…「7」は7枚、合計28枚
- あなた7枚、CPU7枚、表向き場札7枚、伏せ札7枚
- あなたからは自分の手札だけ見えない
- CPUの手札と表向き場札を見て、1〜7を押して推理
- 正解なら1枚減り、そのまま続けて推理
- 不正解ならCPUへ交代
- CPUも正解中は連続推理し、不正解であなたへ交代
- 先に手札を0枚にした側が勝利
- CPUは、見えている数字の枚数と伏せ札を考慮して確率的に推理
- 対戦履歴を表示
- 「新しいゲーム」で即再戦

# 3. 一番簡単な公開方法

GitHub と Streamlit Community Cloud を使います。

## STEP 1：ZIPを解凍する

1. `domemo_mvp.zip` をダウンロードします。
2. Windowsの「ダウンロード」フォルダを開きます。
3. `domemo_mvp.zip` を右クリックします。
4. 「すべて展開」を押します。
5. 展開後の `domemo_mvp` フォルダを開きます。
6. `app.py` と `requirements.txt` が見えることを確認します。

## STEP 2：GitHubで新しいリポジトリを作る

1. ブラウザで GitHub を開きます。
2. GitHubにログインします。
3. 右上の「＋」を押します。
4. `New repository` を押します。
5. `Repository name` に次を入力します。

```text
domemo-mvp
```

6. 公開して問題なければ `Public` を選びます。
7. `Add a README file` にはチェックを入れなくて構いません。
8. `Create repository` を押します。

## STEP 3：GitHubへファイルを入れる

1. 作成した `domemo-mvp` リポジトリを開きます。
2. `uploading an existing file` を押します。
   - 見つからない場合は `Add file` → `Upload files` を押します。
3. Windowsで展開した `domemo_mvp` フォルダを開きます。
4. 次の4ファイルを選びます。

```text
app.py
requirements.txt
README.md
review_check.py
```

5. 4ファイルをGitHubの画面へドラッグ＆ドロップします。
6. 下へスクロールします。
7. `Commit changes` を押します。
8. GitHubの一覧に `app.py` と `requirements.txt` が表示されれば完了です。

# 5. 遊び方

## あなたの番

画面下の `1`〜`7` から、自分の手札にあると思う数字を1つ押します。

### 正解した場合

- あなたの手札が1枚減ります。
- 正解した数字が場に追加されます。
- そのままあなたの番が続きます。

### 不正解の場合

- 手札は減りません。
- CPUの番になります。

## CPUの番

CPUは自動で推理します。

- 正解した場合：CPUが続けて推理
- 不正解の場合：あなたの番へ戻る

## 勝利

先に手札を0枚にした側が勝利です。

# 6. CPUの考え方

CPUは自分の本当の手札を直接参照して答えを決めているわけではありません。

CPUが推理に使うのは次の情報です。

- あなたの手札
- 場に表向きになっているタイル
- 各数字が全部で何枚あるか
- 伏せ札が7枚あること
- CPU自身が以前に外した数字

例えば「7」は全部で7枚あります。
見えている場所に7が2枚しかなければ、残り5枚は「CPU自身の手札」または「伏せ札」のどちらかにあります。
この情報から、CPU自身が少なくとも1枚持っている確率を計算し、最も可能性の高い数字を選びます。

# 8. 修正するときの一番簡単な方法

今後、ChatGPTから新しい `app.py` を受け取った場合は次の手順だけで更新できます。

1. GitHubの `domemo-mvp` を開く。
2. `app.py` をクリックする。
3. 右上付近のゴミ箱アイコンで古い `app.py` を削除する、または新しいファイルで上書きする。
4. `Add file` → `Upload files` を押す。
5. 新しい `app.py` をドラッグ＆ドロップする。
6. `Commit changes` を押す。
7. Streamlit Cloudが自動で再起動する。

通常、Streamlit側でアプリを作り直す必要はありません。

# 11. 音声入力（5歳児向け）

今回の版では、数字ボタンに加えて音声でも答えられます。

## 使い方

1. 自分の番になったら `🎤 おして はなす` を押します。
2. `1`〜`7` の数字を1つ言います。
   - 例：`ご`、`なな`、`よん`
3. 話し終わったら `⏹️ おわり` を押します。
4. 認識できた数字が、そのままDOMEMOの回答になります。

次の言い方に対応しています。

- 1：いち
- 2：に
- 3：さん
- 4：よん / し
- 5：ご
- 6：ろく
- 7：なな / しち

数字そのものの `1`〜`7` が音声認識結果として返った場合にも対応します。

## 初回だけ必要なマイク許可

スマートフォンで最初に音声入力を押すと、ブラウザからマイク利用の確認が出る場合があります。

1. `許可` を押してください。
2. 誤って `許可しない` を押した場合は、ブラウザのサイト設定からマイクを許可してください。
3. マイクが使えない場合でも、画面の大きな数字ボタンで通常どおり遊べます。
